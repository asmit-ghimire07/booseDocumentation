Class BooseCanvas

Namespace

A fully functional implementation of the BOOSE BOOSE.ICanvas interface using real GDI+ graphics. All drawing operations are performed on an in-memory Bitmap that can be displayed in a PictureBox or saved to file.

Remarks

This class replaces the broken/incomplete Canvas from the original BOOSE.dll. It supports all required turtle-style graphics commands with correct behaviour.
