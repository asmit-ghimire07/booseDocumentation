Namespace BooseSoftware.Commands

Classes

MyCircle

Implements the BOOSE CIRCLE command with support for filled circles. Replaces the broken original Circle class from BOOSE.dll.

MyClear

Clears the canvas to white and resets pen position to (0,0).

MyDrawTo
MyMoveTo

Moves the pen to a new position without drawing a line.

MyPenColour

Changes the current drawing colour using RGB values. Accepts both "pencolour" and "pen" keywords.

MyRect

Draws a rectangle starting from the current pen position (top-left corner). Supports optional filled mode.

MyReset

Clears the canvas and resets pen colour to black.

MySetCanvas

Resizes the canvas while preserving existing content.

MyTri

Draws an upward-pointing triangle with base at the current pen position.

MyWriteText

Draws text at the current pen position using the current pen colour. Does not move the pen.
